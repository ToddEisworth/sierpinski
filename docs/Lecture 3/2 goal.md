# Goal

## Theorem

Assume that

$$
\lambda\longrightarrow(\omega_1)^{2n}_{2^{\aleph_0}}
$$

and let

$$
\mathbb P=\operatorname{Add}(\omega,\lambda).
$$

If $G\subseteq\mathbb P$ is generic, then in $V[G]$ there is a ccc forcing $\mathbb Q$ whose generic extension contains an uncountable set $A\subseteq B$, an injection

$$
F:A\longrightarrow 2^\omega,
$$

and a perfect skew tree $T\subseteq2^{<\omega}$ such that

$$
F[A]\subseteq[T]
$$

and $d$ is $F$-canonical on $A$. That is, if $a,b\in[A]^n$ and the ordered configurations determined by $F(a)$ and $F(b)$ have the same similarity type, then

$$
d(a)=d(b).
$$

Consequently,

$$
\left|d''[A]^n\right|\leq n!(n-1)!.
$$


### Corollary

If $G$ is a generic subset of $\mathbb{P}$ then in $V[G]$ for any coloring $c:[2^{\aleph_0}]^n\rightarrow \sigma<\omega$ there is a countable dense-in-itself $X$ on which $c$ takes on at most $n!(n-1)!$ colors.

### Corollary

If we add $\beth_\omega$ Cohen reals to a model of ZFC, then in the generic extension for any $n<\omega$ and any finite coloring of $[\mathbb{R}]^n$ there is a topological copy of the rationals on which the coloring takes at most $n!(n-1)!$ colors.
