# 16. The Final Canonization Theorem

## The theorem

!!! theorem "Canonical triples after Cohen forcing"

    Let

    \[
    P=\operatorname{Add}(\omega,\delta),
    \]

    let \(B\) have order type \(\omega_1\), and let

    \[
    \dot d:[B]^3\longrightarrow r
    \]

    be a \(P\)-name for a finite coloring. Assume the higher-dimensional support
    system, commuting canonical isomorphisms, and exact intersections described
    above.

    Then there is a \(P\)-name \(\dot Q\) such that

    1. \(P\Vdash\dot Q\) is Knaster; and
    2. \(P*\dot Q\) adds an uncountable \(A\subseteq B\) and a fixed map

       \[
       H:\operatorname{Typ}^{\mathrm{ord}}_3\longrightarrow r
       \]

       satisfying

       \[
       d(t)=H\bigl(\operatorname{simtp}_{\mathrm{ord}}(F[t])\bigr)
       \qquad(t\in[A]^3).
       \]

    Consequently, \(d\restriction[A]^3\) assumes at most

    \[
    3!2!=12
    \]

    values.

## Proof

The higher-dimensional \(\Delta\)-system supplies supports \(b_s\) with exact
intersections and commuting canonical isomorphisms. The finite-diagram calculus
therefore permits coherent face data to be united, strengthened, and copied.

Canonical seeds give decisive representatives for every ordered strong
similarity type. Packet completion yields finite capture, and the
resolution-extension lemma permits the resulting interpretation systems to be
built as the construction proceeds.

The prepared-position game simultaneously lengthens a skew tree and preserves
a fixed ordered-similarity palette \(H\). The relative one-split extension lemma
gives Player I a winning strategy. In particular, prepared states can be
lengthened below arbitrary finite compatible Cohen information.

For twin prepared states, the old diagrams agree on all overlaps. Their union
is therefore compatible. The twin-extension lemma lengthens the two-wing
configuration, constructs the missing cross faces, and captures all cross
triples below any prescribed common Cohen extension.

Using the winning strategy, define the ground forcing \(Q^*\) and its complete
projection onto \(P\). The \(\Delta\)-system thinning to twins, followed by the
relative twin-extension lemma, proves

\[
P\Vdash Q_G\text{ is Knaster}.
\]

Finally, relative promotion makes the sets demanding new kept points above
each \(\xi<\omega_1\) dense. A \(Q_G\)-generic filter therefore produces an
uncountable set \(A\) and an infinite skew tree \(T\). Every triple
\(t\in[A]^3\) occurs in one finite marked condition, whose Cohen coordinate lies
in \(G\) and extends the interpretation condition for \(t\). Hence

\[
d(t)=H\bigl(\operatorname{simtp}_{\mathrm{ord}}(F[t])\bigr).
\]

This proves the theorem. \(\square\)

## Proof dependencies

The argument uses the following chain:

\[
\text{exact supports}
\Longrightarrow
\text{finite diagrams}
\Longrightarrow
\text{finite capture}
\Longrightarrow
\text{winning strategy}
\Longrightarrow
\text{twin extension}
\Longrightarrow
\text{Knaster forcing}.
\]

The passage from ordered strong similarity to ordered similarity is performed
inside the skew-tree game through the fixed palette \(H\); no post-forcing
canonization is required.
